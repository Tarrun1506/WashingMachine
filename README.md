# WashingMachine — Simple Console Version

This branch provides the WashingMachine application with regular console menus and printed status instead of a live dashboard.

Run the app from the `WashingMachine` project directory with `dotnet run`.

The application retains wash settings and programs, clothes management, pause/resume/cancel, saved favourites, wash history, JSON persistence, and interrupted-cycle recovery. Machine state is printed when a menu is shown; cycle completion is reported in the console.
